# MiraiNote Skill 管理与调用

MiraiNote 从每位用户的私有 Agent 工作区发现 Skill。工作区相对路径 `skills/yahoo-transit-jp` 对应服务器上的 `{WorkspaceRoot}/users/{用户ID}/skills/yahoo-transit-jp/`；目录内需有 `SKILL.md`。现有目录无需导入数据库，部署新后端后会自动出现在「技能管理」中。若该目录不出现，先核对它是否位于当前登录用户的私有工作区，而不是仓库目录或公共工作区。

`SKILL.md` 采用 Codex 风格的名称、触发描述与正文：

```markdown
---
name: yahoo-transit-jp
description: 查询日本铁路、地铁和公交的路线与换乘时使用。
---

先确认出发地、目的地和时间；再查询实时来源；明确区分已核实和未核实的信息。
```

名称必须与目录名一致，使用小写字母、数字、`-` 或 `_`，最多 64 个字符。描述应说明何时使用，而不仅是 Skill 标题；描述没有单独的字数限制，新建时支持多行输入。`SKILL.md` 整体最大 64 KB。其他参考文件与脚本可保留在同一目录；编辑 Skill 时不会删除它们。

调用方式：

- 显式：在聊天输入框输入 `$` 再按空格，会显示可用 Skill；继续输入名称可筛选，按方向键和 Enter 或点击候选即可补全。也可以直接输入 `$yahoo-transit-jp 东京站到京都站明天上午怎么走`，或点击输入区的 Skill 图标选择。服务端会在该轮加载完整 `SKILL.md`。
- 自动：启用「允许根据请求自动调用」后，Mirai 先看到名称和描述；请求匹配时通过只读 `load_skill` 工具读取完整步骤。关闭自动调用后，`$名称` 仍可显式调用。
- 停用：完全从聊天可用列表移除，但保留目录。删除：将整个 Skill 目录移至私有工作区 `skills/.trash/`，便于管理员恢复。

Skill 是用户自建的工作流程，不会改变现有权限：对话模式仍只开放只读工具，工作模式仍遵守危险操作确认。`SKILL.md` 中的脚本不会因被发现而自动执行。调用结果是否包含实时交通信息，取决于 Skill 指令、可用工具和上游数据源；不要把模型生成的路线当作已核实的实时班次。
